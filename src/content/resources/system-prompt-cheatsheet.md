## Is sheet ko kaise use karein

1. PDF download karo, ya neeche wali image phone mein save kar lo.
2. Apna system prompt chuno: DSA mentor, mock interviewer, code reviewer, resume reviewer ya viva examiner.
3. `[Bracket]` waali jagah apni detail bharo, aur brackets hata do.
4. Use nayi chat ke **sabse pehle message** mein paste karo. Uske baad apna sawal bhejo.

Har system prompt 4 cheezon par bana hai: **Role, Rules, Format, aur "pata na ho to bolo pata nahi".** Ye AI Explained Episode 12 mein samjhaya gaya hai.

## 3 rules

- **Chhota rakho.** System prompt har request ke saath jaata hai, isliye uske tokens har baar lagte hain.
- **Secret mat likho.** Password ya API key isme mat rakho. System prompt leak ho sakta hai.
- **Apna bot bana rahe ho?** Access check apne code mein karo, system prompt ke bharose nahi.
