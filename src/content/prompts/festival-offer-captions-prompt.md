## Kab use karein

Diwali, Holi, Eid ya kisi bhi festival se pehle, jab offer post karna hai aur caption nahi soojh raha.

## Kaise use karein

1. Prompt copy karo, ChatGPT mein paste karo.
2. `[kya bechte ho]` ki jagah apna product likho. Chaho to offer bhi jodo, jaise discount ya last date.
3. Send karo. 3 captions mein se jo pasand aaye, use apne hisaab se thoda badlo.

## Tip

Agar tumhari pichhli koi post achhi chali thi, to prompt ke end mein likho "Is style mein likho:" aur wo caption paste karo. AI usi style ko copy karega.
