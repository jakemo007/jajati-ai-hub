## Kab use karein

Jab koi topic class mein ya book mein samajh nahi aaya, aur tumhe simple explanation ke saath practice bhi chahiye.

## Kaise use karein

1. Prompt copy karo, ChatGPT mein paste karo.
2. `[topic]` ki jagah apna topic likho. Class alag hai to "class 12" bhi badlo.
3. Send karo. Pehle 5 points padho, phir answers dekhe bina 3 sawal khud solve karo.
4. Last mein answers se match karo.

## Dhyan rahe

AI kabhi-kabhi galat fact ya galat answer de deta hai (isse hallucination kehte hain, Episode 3 dekho). Exam ke liye formula, dates aur numbers apni textbook se zaroor check karo.
